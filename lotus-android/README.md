# Sistema Lotus Android v0.1.0

Primeira versão mobile da Lotus Distribuidora.

Inclui dashboard financeiro mensal, produtos e estoque com fornecedor/custo/revenda/lucro, clientes, orçamento editável com desconto por item e geral em R$ ou %, Pix, cartão parcelado com tarifa e opção de repasse, finalização de venda com baixa automática de estoque, PDF de orçamento, PDF de recibo e dados/logo da empresa.

Os dados são armazenados localmente no aparelho nesta versão de teste.
