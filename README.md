# Crônicas de Valedouro — Godot CI

Bancada técnica do projeto **Crônicas de Valedouro** para validação automática com Godot 4.7.2.

Fluxo: reconstrução do projeto → geração determinística dos assets → validação estática → Godot 4.7.2 → smoke/runtime → capturas de auditoria visual.

A build completa de produção permanece preservada fora deste repositório; este workspace é usado para CI e iteração técnica/visual.
